Как поставить

Android спросит разрешение один раз. Windows покажет SmartScreen — это обычное предупреждение, не вирус.

  1. 1
    Скачай сборку

    APK для Android или архив для Windows. Кнопка ведёт на свежий файл из релиза.

  2. 2
    Разреши установку

    Android: «Установить» в браузере. Windows: «Подробнее» → «Выполнить в любом случае».

  3. 3
    Открой

    Дальше как обычно. Обновления — там же, на GitHub.

Что такое Aniplace?

Каталог аниме и дунхуа: 24 000+ тайтлов, расписание новинок, поиск и фильтры, списки и коллекции. Русский и английский, светлая и тёмная темы.

А Mangaplace уже можно скачать?

Пока нет. Первая публичная сборка готовится. Следи за релизами на GitHub — кнопки здесь обновятся сами.

Это бесплатно и без аккаунта?

Да. Ни подписок, ни регистрации. Списки, история и настройки хранятся на устройстве.

Почему нет Google Play?

Раздаём напрямую через GitHub и RuStore, чтобы обновления выходили быстрее. Инструкция — здесь.

На каких платформах работает?

Android 7.0+ и Windows 10/11. Версий для iPhone, iPad и Linux нет.

Это безопасно?

APK подписан, контрольные суммы лежат в релизе. Сверь их, если хочешь убедиться, что файл не подменили.
