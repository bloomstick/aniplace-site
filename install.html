Релиз появится здесь

Публичной сборки пока нет. Следи за релизами на GitHub — как только файлы появятся, эта страница обновится.

Следить за релизами
  1. 1
    Скачай APK

    Нажми «Скачать APK» выше. Файл придёт из GitHub Releases; дождись уведомления «Загрузка завершена».

  2. 2
    Открой файл

    Нажми на уведомление или открой Файлы → Загрузки (в Chrome — ⋮ → Скачанные файлы) и тапни по APK.

  3. 3
    Разреши установку из браузера

    Если система показала «Установка заблокирована» — нажми Настройки и включи установку для своего браузера. Путь: Настройки → Приложения → Доступ к приложениям → Установка неизвестных приложений.

    Системное окно«Установить приложение?» → Установить. На Samsung путь называется «Установка неизвестных приложений», на Xiaomi может появиться дополнительное окно «Безопасность».
  4. 4
    Открой и разреши уведомления

    После установки нажми «Открыть». При первом запуске разреши уведомления — так видно прогресс скачивания серий вне приложения.

  1. 1
    Скачай сборку для Windows

    Нажми кнопку выше. GitHub отдаст актуальный файл: установщик .exe или portable .zip с Aniplace.exe внутри.

  2. 2
    Установи или распакуй

    Если скачался .exe — запусти установщик и следуй подсказкам. Если .zip — правой кнопкой → Извлечь всё… и запусти Aniplace.exe из папки, не из архива.

  3. 3
    Пройди SmartScreen

    Windows может показать синее окно — это нормально для программы без платной подписи издателя.

    SmartScreenНажми «Подробнее», затем «Выполнить в любом случае». Если сумма из релиза совпала — файл тот, что мы опубликовали.
  4. 4
    Если что-то пошло не так

    Антивирус может ругаться на portable-сборку — добавь папку в исключения. Просит DLL — поставь Microsoft Visual C++ Redistributable (x64) с сайта Microsoft.

Проверить файл

SHA-256 — это отпечаток файла. Если он совпал с суммой в релизе, файл не подменили и он скачался целиком. Скачай SHA256SUMS.txt и сравни:

certutil -hashfile aniplace-latest-android.apk SHA256

Windows — certutil, macOS и Linux — shasum -a 256 имя-файла. На телефоне проще приложением для проверки контрольных сумм.

Застрял? Разбор частых случаев
Android пишет «Приложение не установлено»

Проверь, что скачался полный файл (размер совпадает с релизом), и разрешена установка именно для браузера, из которого ты открываешь APK. Если раньше стояла старая сборка с другим идентификатором — удали её и поставь заново.

Play Protect предупреждает

Это стандартная проверка для APK вне Google Play. Нажми «Подробнее» → «Установить всё равно», если сумма SHA-256 совпала с релизом.

Windows SmartScreen не даёт запустить

«Подробнее» → «Выполнить в любом случае». Если кнопки нет, проверь, что файл распакован, а не запускается из ZIP.

Не запускается на Windows

Поставь Microsoft Visual C++ Redistributable (x64) и обнови WebView2. Если антивирус удалил файл — добавь папку в исключения и распакуй заново.

Короткая инструкция

Выбери файл на GitHub Releases:

  • Android: скачай aniplace-*-android.apk, открой файл и разреши установку из браузера.
  • Windows: скачай сборку (aniplace-*-windows.zip или aniplace-*-windows-setup.exe); распакуй ZIP или запусти установщик. SmartScreen — «Подробнее» → «Выполнить в любом случае».
  • Mangaplace: публичной сборки пока нет — следи за релизами.

Если что-то не получилось — напиши нам.
