Установка за 5 минут

Aniplace распространяется напрямую (мимо магазинов приложений), поэтому Android и Windows попросят одно подтверждение. Ниже — каждый шаг подробно.

⬇ Скачать с GitHub Releases Сразу к Android Сразу к Windows
🤖 Android 8.0+

Установка APK на телефон

⚠️ Файл скачивается из интернета, а не из Google Play — так и задумано. Сверь SHA-256 сумму со страницей релиза (инструкция в конце), и всё будет безопасно.
1

Скачай APK-файл

На телефоне открой страницу последнего релиза и нажми на файл aniplace-*-android.apk. Дождись окончания загрузки — в шторке появится уведомление «Загрузка завершена».

2

Открой скачанный файл

Нажми на уведомление о загрузке либо открой Файлы → Загрузки (или Chrome → ⋮ → Скачанные файлы) и тапни по aniplace-*.apk. Появится системное окно «Установить приложение?».

📱 Как это выглядит: системное окно с иконкой Aniplace, кнопками «Отмена» / «Установить» и списком разрешений.

3

Разреши установку из этого источника (один раз)

На Android 8 и новее разрешение выдаётся точечно — только твоему браузеру:

  1. Если система показала «Установка заблокирована» — нажми Настройки в этом же окне.
  2. Откроется пункт Установка из неизвестных источников / Install unknown apps — включи переключатель для браузера (Chrome, Firefox и т.п.).
  3. Вернись назад и нажми Установить.

Путь вручную: Настройки → Приложения → Доступ к приложениям → Установка неизвестных приложений → твой браузер → Разрешить. На Samsung: Настройки → Биометрия и безопасность → Установка неизвестных приложений. На Xiaomi (MIUI): может понадобиться также разрешить во всплывающем окне «Безопасность».

📱 Как это выглядит: список приложений с тумблером «Разрешить установку из этого источника» — включи его для своего браузера.

4

Подтверди установку и открой приложение

Нажми Установить и подожди 10–30 секунд. Когда появится «Приложение установлено» — жми Открыть. Иконка 🌸 Aniplace уже на домашнем экране!

При первом запуске разреши уведомления — так ты узнаешь о новых сериях первым.

5

Проверь файл (необязательно, но надёжно)

На странице релиза есть SHA256SUMS.txt. Сравни сумму любым приложением для проверки SHA-256 или командой на компьютере: sha256sum aniplace-*.apk. Суммы совпали — файл подлинный.

🖥️ Windows 10 / 11

Запуск на компьютере

1

Скачай ZIP-сборку

На странице последнего релиза скачай файл aniplace-*-windows.zip (portable — установка не нужна).

2

Распакуй архив

Кликни по ZIP правой кнопкой → Извлечь всё… и выбери папку, например Документы\Aniplace. Важно: запускай из распакованной папки, а не изнутри архива.

3

Запусти Aniplace.exe

Открой папку и дважды кликни Aniplace.exe. Если Windows SmartScreen покажет синее окно «Система Windows защитила ваш компьютер»:

  1. Нажми Подробнее.
  2. Нажми Выполнить в любом случае.

Это стандартное предупреждение для программ без платной подписи издателя — приложение при этом безопасно, особенно если сошлась SHA-256 сумма из релиза.

🖥️ Как это выглядит: синее окно SmartScreen → ссылка «Подробнее» → кнопка «Выполнить в любом случае». (Фото-скриншоты с реального устройства добавим перед публичным запуском.)

4

Если что-то пошло не так

  • Антивирус ругается? Добавь папку Aniplace в исключения — эвристика часто реагирует на portable-сборки.
  • Просит DLL / Visual C++? Установи Microsoft Visual C++ Redistributable (x64) с сайта Microsoft.
  • Ничего не помогло? Создай issue — укажи версию Windows и текст ошибки.
