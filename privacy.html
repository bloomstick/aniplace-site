Политика конфиденциальности Aniplace

Редакция от 3 ноября 2026 года. Применяется к приложению Aniplace для Android и Windows и к сайту ani.place.

Оператор: владелец приложения Aniplace. Контакт ответственного за обработку персональных данных: aniplace.app@gmail.com.

Aniplace не создаёт учётные записи, не требует почту или телефон и не продаёт данные. Приложение работает без регистрации.

1. Какие данные обрабатываются

1.1. Данные на устройстве

Настройки приложения, списки, история просмотра, прогресс, избранное, сохранённые эпизоды и параметры синхронизации хранятся локально на вашем устройстве. Они не отправляются на наши серверы. При синхронизации по локальной сети данные передаются напрямую между вашими устройствами по Wi-Fi; облачный посредник не используется.

1.2. Необязательная статистика использования

С первого запуска приложение отправляет обезличенные счётчики событий без идентификатора установки. В одном из первых запусков показывается запрос: можно привязать случайный идентификатор установки (полная статистика) или оставить счётчики анонимными. Статистику можно полностью отключить в настройках. Приложение отправляет:

  • обезличенные счётчики событий (запуск, открытие экрана, воспроизведение, использование функций);
  • технические сведения: семейство и версия ОС, язык интерфейса, версия приложения;
  • в полном режиме — случайный идентификатор установки, который создаётся на устройстве и не связан с вами, аккаунтом или рекламным идентификатором.

В статистике мы не передаём имя, почту, телефон, контакты, геолокацию, рекламный идентификатор или содержимое ваших файлов. IP-адрес не включается в полезную нагрузку события; принимающий сервис может обрабатывать технические данные соединения для доставки запроса. Рекламный SDK использует рекламный идентификатор отдельно — см. п. 1.6.

1.3. Проверка обновлений

Прямые сборки (с GitHub) обращаются к публичному API GitHub, чтобы проверить наличие новой версии; при этом GitHub получает обычные технические данные HTTP-запроса. Сборка для RuStore не выполняет эту проверку: обновления приходят через RuStore.

1.4. Разрешения устройства

Камера запрашивается только при нажатии «Сканировать QR» в мастере синхронизации по локальной сети. Отказ от камеры не мешает ручному вводу кода. Состояние Wi-Fi и multicast-lock используются для поиска устройств в локальной сети; пароли и содержимое сети не читаются. Доступ в интернет нужен для каталога, обложек и видеопотока. Приложение не запрашивает геолокацию, контакты, SMS, доступ к файлам или установке других приложений.

1.5. Обращения в поддержку

Если вы пишете на aniplace.app@gmail.com, мы получаем адрес отправителя, текст письма и вложения, которые вы отправите. Они используются только для ответа и решения вопроса.

1.6. Персонализированная реклама

В Android-приложении показывается реклама Yandex Mobile Ads (ООО «Яндекс»). Для подбора рекламы SDK может обрабатывать рекламный идентификатор устройства, IP-адрес, технические данные устройства и сведения о показах и кликах. Персонализация включена; отключить её можно в настройках Android в разделе рекламы (Google → Реклама), сбросив или ограничив рекламный идентификатор. Windows-сборка рекламу не показывает.

Политика конфиденциальности Яндекса: https://yandex.ru/legal/confidential/.

2. Цели и правовые основания

  • Работа приложения: хранение настроек, списков, истории и загрузок — исполнение договора с пользователем и законный интерес в предоставлении функций.
  • Статистика: понимание того, какие функции востребованы, и исправление ошибок — ваше согласие, которое можно отозвать в любой момент.
  • Поддержка: ответ на обращение — ваше обращение и законный интерес в поддержке.
  • Безопасность и право: соблюдение применимых требований законодательства.

3. Кому передаются данные

  • PostHog — приёмник необязательной статистики. Получает только перечисленные выше обезличенные события.
  • Yandex Mobile Ads — показ персонализированной рекламы в Android-приложении. Получает рекламный идентификатор, IP-адрес и сведения о показах/кликах в объёме, описанном в п. 1.6.
  • GitHub — публичный API проверки обновлений в прямых сборках и хостинг страницы проекта.
  • RuStore — магазин приложений, через который распространяется сборка для RuStore.
  • Провайдер почты — обработка писем, которые вы отправляете в поддержку.

Мы не продаём персональные данные и не передаём их для рекламы. Передача возможна только в случаях, предусмотренных законом, или с вашего отдельного согласия.

4. Сроки хранения и удаление

  • Локальные данные хранятся до удаления приложения или очистки данных. Удалить их можно в приложении: «Настройки» → «Хранилище» → удаление данных, либо удалив приложение.
  • Статистика хранится не более 12 месяцев с даты сбора. Согласие отзывается переключателем в «Настройках» → раздел статистики; после отзыва новые события не отправляются.
  • Рекламные данные обрабатываются Yandex Mobile Ads по его правилам и срокам; персонализацию можно отключить в настройках Android, как описано в п. 1.6.
  • Письма в поддержку хранятся до завершения обращения и разумного срока после него, если закон не требует иного.
  • Учётной записи нет, поэтому отдельное удаление аккаунта не требуется.

5. Ваши права

Вы вправе запросить информацию об обработке ваших данных, потребовать их уточнения, блокирования или удаления, отозвать согласие и обратиться с жалобой в уполномоченный орган. Для этого напишите на aniplace.app@gmail.com. Мы ответим в срок, установленный законом.

6. Дети

Приложение предназначено для пользователей 16 лет и старше и не адресовано детям. Мы сознательно не собираем данные детей. Если вы считаете, что ребёнок передал нам данные, напишите нам — мы удалим их.

7. Файлы cookie и локальное хранилище сайта

Приложение не использует рекламные cookie, но рекламный SDK Yandex Mobile Ads обрабатывает рекламный идентификатор и сведения о показах (см. п. 1.6). Сайт ani.place может сохранять в браузере технические настройки (например, выбранную тему) в локальном хранилище; рекламные трекеры на сайте не подключены. Хостинг-провайдер может вести стандартные журналы обращений.

8. Изменения политики

Мы можем обновлять эту политику. Новая редакция публикуется на этой странице с датой. Существенные изменения, затрагивающие согласие, мы дополнительно показываем в приложении.

Контакт: aniplace.app@gmail.com
